# manim_workshop
Starship app to prepare a manim workshop.

# Build locally

This Astro project requires node >= 22.19.0

1. Clone the repo.
```sh
git clone https://github.com/UnMolDeQuimica/manim_workshop.git
cd manim_workshop
```

2. Install npm dependencies
```
npm install
```

3. Start the dev server
```
npm run dev
```

# Run the examples

To run the examples, you must follow the tutorial.
