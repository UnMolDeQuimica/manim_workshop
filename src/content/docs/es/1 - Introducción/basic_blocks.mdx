## Esquema general
Después de haber creado nuestras primeras animaciones, vamos a entrar un poco más en detalle. Abajo podemos ver un diagrama resumen sobre como se conectan las principales piezas de `Manim`. 

<Image src="/images/manim-diagram-es.svg"/>


## En pocas palabras
- En el código se define una clase que hereda de la clase `Scene` y se sobreescribe el método `construct` para definir nuestra escena.
- En nuestra escena tendremos instancias de clases llamadas `MObjects` sobre las cuales podemos aplicar `Animations`.
- La clase `Scene` instancia un `Manager` encargado de coordinar los distintos pasos del renderizado.
- El `Manager` llama a los diferentes `Renderers` para que, a través de las `Cameras` capturen a los `MObjects` de una escena y las transformaciones que las `Animations` aplican sobre ellos.
- La información enviada de las `Cameras` a los `Renderers` es procesada y mandada al `SceneFileWriter` para que genere los archivos finales, ya sean imágenes o videos.

<Aside type="tip">
Esto es solo un resúmen corto y sencillo para que entendamos brevemente cómo funciona `Manim` por dentro. Para más detalles <a href="https://docs.manim.community/en/stable/guides/deep_dive.html" target="_blank">ve a la documentación</a>.
</Aside>

A continuación nos iremos adentrando de forma más profunda en cada uno de estos componentes para ir entendiendo cómo podemos utilizarlos para generar animaciones, pero antes de eso debemos entender la anatomía de una escena de `Manim`.
