Con `Manim` tenemos 5 formas principales de agregar texto a nuestra escena:

- `Text`: Usado para texto normal.
- `Tex`: Enfocado a escribir fórmulas con `Tex`.
- `Typst`: Similar a `Tex` pero usando el motor `Typst`.
- `MarkupText`: Usado para dar estilo al texto como si fuera Markup.
- `Code`: Permite agregar bloques de código con resaltado de síntaxis incluido.

En este taller no utilizaremos `Tex` porque requiere instalar una distribución de `Tex` y no nos da tiempo. Haremos llorar a Donald Knuth pero es lo que hay.

<Aside>Hay toda una página de la documentación dedicada al texto. <a href="https://docs.manim.community/en/latest/guides/using_text.html" target="blank">¡Échale un ojo!</a></Aside>

## Text

La forma más sencilla de dibujar texto en `Manim` es con la clase `Text`. A esta podemos pasarle una cadena de texto y varios parámetros como el tipo, tamaño y grosor de la fuente, color, y mucho más.

La clase `Text` utiliza `Manim Pango`, una adaptación en C de la librería `Pango` para renderizar texto.

## Typst

Como hemos comentado antes, vamos a ignorar la clase `Tex` y usaremos una muy similar: `Typst`. Tanto `Tex` como `Typst` son compositores tipográficos hechos para escribir textos académicos con un gran enfoque hacia las matemáticas.

Con la clase `Typst` podemos escribir texto usando formato <a href="https://typst.app/docs/" target="blank">`Typst`</a>:
