## Instal·lació

Hi ha diverses maneres d'instal·lar `Manim`. En aquest taller seguirem el mètode recomanat per la documentació:

<Steps>
1. Instal·lar `uv` i altres dependències:

   <Tabs syncKey="os">
     <TabItem label="Windows" icon="seti:windows">
       <Code code={'powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"'}  lang='sh'/>
     </TabItem>

     <TabItem label="MacOS" icon="apple">
       <Steps>

       1. Instal·lar el gestor de paquets i projectes `uv`:
          <Code code={'curl -LsSf https://astral.sh/uv/install.sh | sh'}  lang='sh'/>

       2. Instal·lar `brew`. Potser alguns ja el teniu.
          <Code code={'/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"'}  lang='sh'/>

       3. Instal·lar `cairo` i `pkg-config`:
          <Code code={'brew install cairo pkg-config'} lang='sh'/>

       </Steps>
     </TabItem>

     <TabItem label="Linux" icon="linux">
       <Steps>
       1. Instal·lar el gestor de paquets i projectes `uv`:
          <Code code={'curl -LsSf https://astral.sh/uv/install.sh | sh'}  lang='sh'/>
       2. Instal·lar les biblioteques necessàries segons la vostra distribució:
          <Tabs>
            <TabItem label="Debian-Ubuntu">
              <Code code={'sudo apt update\nsudo apt install build-essential python3-dev libcairo2-dev libpango1.0-dev'} lang='sh'/>
            </TabItem>
            <TabItem label="Fedora">
              <Code code={'sudo dnf install python3-devel pkg-config cairo-devel pango-devel'} lang='sh'/>
            </TabItem>
            <TabItem label="Arch">
              <Code code={'sudo pacman -Syu base-devel cairo pango'} lang='sh'/>
            </TabItem>
          </Tabs>
       </Steps>
     </TabItem>
   </Tabs>

2. Instal·lar una versió adequada de `python` amb `uv`. Recomano una versió superior a la 3.11:
   <Tabs syncKey="os">
    <TabItem label="Windows" icon="seti:windows">
      <Code code={'uv python install 3.13'}  lang='sh'/>
    </TabItem>
    <TabItem label="MacOS" icon="apple">
      <Code code={'uv python install 3.13'}  lang='sh'/>
    </TabItem>
    <TabItem label="Linux" icon="linux">
      <Code code={'uv python install 3.13'}  lang='sh'/>
    </TabItem>
   </Tabs>
3. Crear un entorn virtual amb `uv`:
   <Tabs syncKey="os">
    <TabItem label="Windows" icon="seti:windows">
      <Code code={'uv init manim-workshop\ncd manim-workshop'}  lang='sh'/>
    </TabItem>
    <TabItem label="MacOS" icon="apple">
      <Code code={'uv init manim-workshop\ncd manim-workshop'}  lang='sh'/>
    </TabItem>
    <TabItem label="Linux" icon="linux">
      <Code code={'uv init manim-workshop\ncd manim-workshop'}  lang='sh'/>
    </TabItem>
   </Tabs>
4. Instal·lar `Manim`:
   <Tabs syncKey="os">
   <TabItem label="Windows" icon="seti:windows">
    <Code code={'uv add manim'}  lang='sh'/>
   </TabItem>
   <TabItem label="MacOS" icon="apple">
    <Code code={'uv add manim'}  lang='sh'/>
   </TabItem>
   <TabItem label="Linux" icon="linux">
    <Code code={'uv add manim'}  lang='sh'/>
   </TabItem>
   </Tabs>
5. Instal·lar `Typst`:
   <Tabs syncKey="os">
   <TabItem label="Windows" icon="seti:windows">
    <Code code={'uv add typst'}  lang='sh'/>
   </TabItem>
   <TabItem label="MacOS" icon="apple">
    <Code code={'uv add typst'}  lang='sh'/>
   </TabItem>
   <TabItem label="Linux" icon="linux">
    <Code code={'uv add typst'}  lang='sh'/>
   </TabItem>
   </Tabs>
6. Verificar la instal·lació:
   <Tabs syncKey="os">
   <TabItem label="Windows" icon="seti:windows">
    <Code code={'uv run manim checkhealth'}  lang='sh'/>
   </TabItem>
   <TabItem label="MacOS" icon="apple">
    <Code code={'uv run manim checkhealth'}  lang='sh'/>
   </TabItem>
   <TabItem label="Linux" icon="linux">
    <Code code={'uv run manim checkhealth'}  lang='sh'/>
   </TabItem>
   </Tabs>
</Steps>
