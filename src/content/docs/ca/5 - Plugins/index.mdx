`Manim` tiene una gran comunidad detrás que hace mil y un cosas distintas. Y dado que todo es código `python`, `Manim` es fácilmente extendible.

Como consecuencia, se ha creado todo un ecosistema de plugins que traen mucho trabajo ya hecho para nosotros. 

Podemos encontrar una lista actualizada en el siguiente enlace: https://plugins.manim.community/
