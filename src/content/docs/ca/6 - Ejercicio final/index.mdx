Tot s'ha d'acabar, per sort o per desgràcia. Inclòs el taller.

Com a exercici final, us proposo el següent:

1. Visiteu la documentació.
2. Aneu a la galeria d'exemples.
3. Trastegeu amb els exemples que hi trobareu: proveu-los a la vostra màquina, modifiqueu-los, trenqueu coses.
4. Si trobeu alguna cosa que no funciona, obriu una Pull Request per arreglar-ho. O, si més no, una Issue per avisar-ne!

## Gràcies

Gràcies per venir. Aquest taller s'ha preparat amb molta estima i espero que n'hàgiu gaudit i, sobretot, que hàgiu après alguna cosa nova i interessant.
